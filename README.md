## Final Project Proposal

The application I am going to be devloping is called Auditory. Auditory is a social media app centered around music. 

A few core features will include: 
-Liking Songs (which will add them to the users profile)
-ability to review and rate every song which will also be present on the users profile if visibility marked to public 
- Making posts

The target group will be anyone who loves music, wants to share their love for the game with others, and users who want to expose themselves to new music they would have not seen before. 

For AI integration, I am planning on having an AI model analyze the users prior activity, and then offer personalized recommendations based on said prior activity. 

The tech stack I am plannig to integraete is: 
- **FRONTEND**:
React, Tailwind CSS
- **BACKEND**:
Node.js, Express
- **DATA BASE**: 
MONGO DB
- **AI INTEGRATION**: OPEN AI API 
- **DEPLOYMENT**: 
Docker, Google Cloud
